Как считается. Данные из Битрикс24 (REST) по трём смарт-процессам «Платежи». «Одобрено» — заявки, прошедшие весь маршрут; «Ждут/в работе» — на согласовании, в бухгалтерии или кассе; «Отклонено» — отклонённые/провал. Согласующие: 1-я ступень — ГД (Олеся, стадия «Руководитель»), 2-я — ФД (Ольга, стадия «Фин. директор»); по Астане и O-Live — свои директора соответствующих ступеней. Фильтры: период по датам, подразделение, тип, стадия/пресеты, диапазон суммы, поиск; клик по заголовку — сортировка; «CSV» выгружает отфильтрованное. Столбец 📎 — у заявки есть вложение; «↗» открывает карточку в Битрикс (счёт/КП, история движения по стадиям, комментарии — за входом в Битрикс). Отдельной ленты комментариев процесс не ведёт — роль комментария играет поле «За что». Охват — с запуска процесса (≈ март–сентябрь 2026). «Автор» — заявитель (есть столбец и фильтр); имена подтянуты из Битрикса, для совсем новых сотрудников возможно «—». Суммы — «Общая сумма платежа».
