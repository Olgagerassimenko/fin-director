8 · Что с этим делать

по убыванию денег
  • Поднять цену. Это единственный канал без премии и без скидки, при этом с самым узким ассортиментом и готовностью брать гофротару. Плюс 5% к цене — это около 1,2 млн ₸ в месяц, что сразу выводит канал в плюс при полной себестоимости.
  • Укрупнить поставки на мелкие точки. АЗС 26 забирает 109 накладных в год при средней 56 тыс. ₸. Таких точек в хвосте десятки — они и делают 19% доставок при 8,7% выручки.
  • Понять природу всплесков. Июль дал 43,4 млн, февраль 11,4. Если это акции сети, их надо планировать заранее: под них нужен другой график производства.
  • Использовать концентрацию. Десять позиций дают 63% канала — это редкая возможность договариваться о цене по короткому списку, а не по всей матрице.
Источник — данные из программы айко: расходные накладные по контрагентам группы «99-», баланс расчётов на 23.10.2026, управленческий ОПиУ за январь–сентябрь для долей затрат. Себестоимость — только продуктовая: 49,2% по заводу за январь–сентябрь с поправкой на индекс цен канала. Сравнение цен — по средней цене каждой позиции по всем каналам за июль–октябрь.
